# Privacy Policy

**Effective Date:** November 1, 2026

This Privacy Policy explains how Scripture Bot ("the Bot") handles data when used on Discord.

## 1. Data We Collect

The Bot may collect and store the following:

- **Server (Guild) IDs** — to store preferences or customization settings specific to each server (for example, enabling or disabling Bible references).
- **Discord User IDs** — collected in connection with specific features you or our trusted users use:
  - When you submit an activity through the Light The World feature (`-ltw`), your Discord User ID is stored alongside the activity text, so trusted users can identify and remove inappropriate submissions if needed.
  - The Discord User IDs of trusted users (a small number of individuals we personally rely on, not an official server moderation role) and of users restricted from submitting activities ("banned users") are stored to enforce those permissions.
- **User-submitted content** — the text of activities submitted through the Light The World feature is stored so it can be displayed to, and browsed by, other members of the server.

We do not log or store the general content of your server messages. See Section 2 for how the Bot processes some message text without storing it.

## 2. Automatic Message Scanning

Some features — for example, scripture lookups — work by scanning message text as it's sent, checking for patterns that match a scripture reference (such as "John 3:16"), so the Bot can automatically respond with the relevant verse. This scanning happens in real time only: the Bot does not log, store, or retain the content of messages it scans, whether or not a match is found.

## 3. Purpose of Data Collection

We collect this data to provide the Bot's features:
- Server IDs let us remember each server's preferences (e.g. whether Bible references are enabled).
- User IDs tied to submitted activities let trusted users review and, if necessary, remove individual submissions, and let us enforce a banned-user list.
- Submitted activity text is stored so it can be shared with and browsed by other members of the submitting server.

## 4. Hosting

The Bot is self-hosted. We do not use a third-party hosting provider, and data processed or stored by the Bot resides on infrastructure we directly control.

## 5. Third-Party Content Sources

Some features (such as the daily verse and daily quote) retrieve publicly available content from The Church of Jesus Christ of Latter-day Saints' website. These requests do not include or transmit any of your personal data — they request the same public page content that anyone visiting the site would see.

## 6. Data Sharing

We do not sell, rent, or share your data with third parties, except as required by law. Submitted activity text and the associated Discord User ID may be visible to our trusted users as part of the Bot's built-in content-removal tools — this is not a third-party disclosure, since those trusted users are part of the community using the Bot.

## 7. Data Retention and Removal

- Server-specific preference data is retained for as long as your server uses the Bot, and may be deleted if the Bot is removed from your server.
- Data associated with the Light The World feature — submitted activities, activities removed by a trusted user, and the associated Discord User IDs — is deleted at the end of each calendar year.
- Activities may also be removed by a trusted user before then; removed activities are kept in an archive, along with the original submitter's Discord User ID, until the year-end deletion.
- You can request manual deletion of your data — including any activities you've submitted — at any time by contacting us (see Section 9), without waiting for the year-end deletion.

## 8. Children's Privacy

The Bot is intended for general audiences. We do not knowingly collect personal data from individuals under 13 years of age. If you believe a child under 13 has submitted data to the Bot, please contact us so we can remove it.
